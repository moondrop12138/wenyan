## 1. 产品目标

1. **记忆可治理、可信任**：已记住的事实从"整段文本"升级为"单条可管理"，档案结构化字段可随时编辑，AI 回答标注「记忆依据」，让用户能看见、能修正、能核对。
2. **稳定性兜底闭环**：修复设置页下滑至记忆分组闪退（P0），崩溃日志本地落盘 + 一键导出，应用内更新检查直达新版本，弥补无后端埋点的短板。
3. **工程质量可信**：Room 迁移 v1→v6 自动化测试 + 记忆相关 UI 测试/@Preview 固化，防老用户数据损坏、防回归。

## 2. 用户故事

- 作为**发现记忆有误的用户**，我想要逐条查看/编辑/删除已记住的事实，以便修正 AI 自动提炼产生的错误，而不影响其他正确记忆。
- 作为**关系状态变化的用户**，我想要在档案详情页直接编辑名称/MBTI/吸引力分/关系状态/关键事件，以便档案跟随现实更新，无需重新 onboarding。
- 作为**谨慎核对 AI 回答的用户**，我想要回答标注「记忆依据」小字并引用实际使用的事实，以便确认 AI 没有编造或错用记忆。
- 作为**同时咨询多对象的用户**，我想要抽屉会话列表按记忆档案分组（未关联归最后），以便快速定位某个人的对话。
- 作为**遇到闪退的用户**，我想要从设置页导出诊断日志，以便把崩溃信息发给开发者定位修复。
- 作为**希望及时升级的用户**，我想要在应用内检查更新并直接下载安装，以便快速用上新版本。

## 4. UI 说明（文字版，对齐计划 §3）

### 4.1 档案详情页 MemoryEditScreen（对齐 §3.1 + §3.2）

```
┌─ 档案详情 ─────────────────────┐
│ 名称        [TextField]        │
│ MBTI        [MbtiPicker 复用]  │
│ 吸引力分    [SliderField 复用] │
│ 关系状态    [分段选择：暧昧中/ │
│             约会/确定关系/前任/ │
│             同事/单恋]         │
│ 关键事件    [列表：时间+事件，  │
│             每行可删，➕新增]   │
│ ── 已记住的事实（时间倒序）──  │
│  · 事实1                    [✎][🗑] │
│  · 事实2                    [✎][🗑] │
│  （✎=弹窗 TextField 编辑；      │
│    🗑=直接删除，不二次确认）    │
└───────────────────────────────┘
```

- 入口：设置页记忆分组档案行「编辑」图标 → 跳详情页（替代 v1.7.2 改名弹窗）。
- 已记住的事实：单条删除**不二次确认**（决策点 3）；超过 50 条时新事实静默丢弃。

### 4.2 记忆依据小字（对齐 §3.3）

- CoachCard 知识引用区旁新增「记忆依据」小节：muted 小字 + 「」引用实际使用的事实原文（≤3 条）；**非空才显示**，无引用时整节隐藏，不影响现有布局。

### 4.3 会话分组组头（对齐 §3.4）

- 每组前加档案名组头（accentSoft 小字，风格对齐「最近会话」标题）；未关联（targetName=null）会话归「未关联」组、放最后。

### 4.4 导出诊断日志入口（对齐 §3.7）

- 设置页「隐私与安全」新增「导出诊断日志」行 → ShareIntent + FileProvider 发送 `last_crash.txt`（无用户内容，红线见 §5）。

### 4.5 更新弹窗（对齐 §3.8）

- 设置页「关于」区「检查更新」行（手动触发）→ 有新版时 AlertDialog（版本说明 notes + 「去下载」按钮）→ 下载 APK → 唤起系统安装器（首次需用户允许"安装未知应用"）；无新版/失败静默或 Toast。

## 5. 隐私与合规

- **崩溃日志红线**：AppLogger 事件格式已含隐私红线，崩溃日志仅含时间戳/线程/堆栈/日志标签与缓冲内容，**绝不包含会话正文与记忆内容**；「导出诊断日志」导出的 last_crash.txt 同样受红线约束。
- **清除联动**：wipeAll 一并删除 crash 目录与下载缓存，随隐私清除无残留。
- **仓库转 public**：GitHub 仓库转为 public 前历史已清洗、许可与致谢已备齐（决策点 1 拍板）；App 直连 GitHub Releases API 仅读取版本元数据与 APK，不采集用户任何信息；安装行为由用户手动触发并授权"安装未知应用"。
- **数据不出手机**：记忆事实、结构化字段仅存本机 Room（v6），延续"数据不出手机"卖点；出网仅限：主模型请求（用户配置的第三方服务）与更新检查（GitHub Releases 元数据/APK 下载）。
