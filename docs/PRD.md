## 1. 产品定义

- **一句话描述**：以 goutoujunshi（狗头军师）开源项目为知识内核、用户自带 API Key 直连 LLM 的恋爱决策支持工具——先接住情绪，再分析关系，给出可执行的下一步。
- **目标用户**：20-35 岁处于暧昧/追求/热恋/关系焦虑/冲突/分手期的年轻人；重视隐私、不愿为虚拟陪伴氪金、深夜情绪峰值需要即时决策支持。
- **核心问题**：现有 AI 恋爱产品要么是"虚拟恋人陪伴"（模板化、付费墙、记忆短、隐私上云），要么是通用 ChatGPT 套 prompt（流程不固定、无专业知识库、无多模态截图分析）。市场缺少一个**专业、克制、流程严谨、数据不出手机**的恋爱决策工具。
- **产品定位**：专业工具，不是娱乐陪伴。区隔"军师帮你决策"与"AI 陪你恋爱"。

## 3. 用户画像

- **主画像**：20-35 岁，暧昧/追求/热恋期或关系焦虑的年轻人。会用 AI 工具，重视隐私，不愿为虚拟陪伴氪金，深夜情绪峰值需要即时决策支持。
- **次画像**：关系冲突/分手/多人选择中的用户，需理性拆解与退出路径；多元关系（LGBTQ+）用户。
- **关键需求**：看懂信号不脑补、能复制的可发送话术、明确下一步 + 停止条件、数据不出手机。

### 4.1 Chatbox 式多提供商模型管理（F8 详细设计）

参考 Chatbox 客户端的成熟机制：

1. **提供商（Provider）**：每个提供商 = 名称 + API Host（Base URL）+ API Key（可选）+ 模型列表
   - **内置预设提供商**（可编辑 Key/地址，模型列表预置只读可增）：DeepSeek / 智谱 / OpenAI / 通义 / Kimi
   - **自定义提供商**：用户完全自定义（名称 + Host + Key + 模型列表），支持 Ollama 等本地/自建服务
2. **模型（Model）**：属于某提供商，字段 = 模型名 + 多模态能力标注（支持看图/仅文本）+ 是否默认
   - 预设模型列表（**已核实截至 2026-08-02 的在役模型**）：DeepSeek V4 系（v4-pro/v4-flash）/ GLM-5.2 / GLM-5V-Turbo / GLM-4V-Flash / GPT-5.6 系（Sol/Terra/Luna）/ Qwen3.7 系 / Qwen3-VL / Kimi K3 / K2.6，带能力标注
   - 用户可在任意提供商下**增删模型**（含预设提供商），完全自行管理
3. **主模型**：从模型库任选一个（对话分析用）；**视觉模型**：从模型库任选一个支持看图的（截图转述用）——**视觉模型由用户自行选择**，不写死
4. **对话中快捷切换**：对话页顶部模型选择器，切换不中断当前对话（后续消息用新模型）
5. **测试连接**：保存提供商后可选测试，返回 200/401/429 明确结果

## 6. 引导流程设计（SKILL.md → 移动端 UX，严格遵循）

1. **首启 4 屏紧凑问卷**：本人资料 → 对象资料 → 关系经过 → 目标+情绪强度。每屏带进度条，底部常驻"跳过，直接讲故事"（对应 SKILL 允许留空 + 紧急例外原则，跳过需二次确认）。
2. **五步法输出为结构化报告卡**：情绪落地 / 事实拆分 / 利益判断 / 明确建议 / 行动收束，可折叠，结论置顶。
3. **"这句怎么回"入口**：第一屏先给可复制成品，再给发送时机、主要代价、积极/含糊/不回应三种后续分支。每条消息只承载一个主动作。
4. **截图导入（双通道）**：主模型为多模态 → 截图直接发主模型；主模型非多模态 → 先经视觉转述通道（用户配置的视觉模型，如 GLM-4V）将截图转为文字描述，再交主模型分析。分析时自动提取可见原文、说话人、顺序、间隔，标注"截图能证明 / 转述提示 / 仍未知"三态，不脑补线下动作。
5. **高情绪强度**（自评 >7）：先出安抚 + 暂存建议，再进完整分析。
6. **知识加载透明**：分析结果展示"本次分析参考了哪份资料"，建立可信感。
7. **安全边界**：出现家暴/跟踪/胁迫/自伤风险时，先安全计划与危机转介（含当地紧急服务），不给恋爱话术。

## 7. 隐私与信任（一级卖点）

- API Key 只存本地（Keystore AES-GCM 加密），支持一键清除全部档案
- 数据不出手机；出网仅发生在用户主动发起分析时，请求发往用户自行配置的第三方服务
- 设置页明示隐私声明："数据将发送至用户配置的第三方模型服务"

## 8. 验收标准摘要（详细见 Spec）

- 首启问卷可完成/可跳过，档案持久化
- 文本粘贴 → 五步法结构化输出，可复制话术
- 截图选择 → 多模态分析（视觉模型）或明确引导换用文本粘贴
- 设置 Key → 对话可用；Key 错误给出明确错误提示
- 危机关键词 → 触发安全转介而非恋爱话术
