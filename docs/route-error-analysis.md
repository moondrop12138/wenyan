# 路由错误分析（v1.9.4 10-01 迭代，默认 LLM 路由档）

> 数据来源：v1.9.4（10-01 迭代）决策门评测产出的 LLM 路由档（本版起为默认档）逐条预测 miss 清单——期望文档集合与预测集合不一致的条目，共 30 条；30 条 query 与期望标注已与主评测集 `app/app/src/test/resources/route_eval_queries.json`（1098 条）逐条核对一致。离线三方法（contains/variant/hybrid）的逐条基线对照见 `RoutePredictionsDumpTest` 导出的 `app/app/build/reports/route-eval/predictions-baseline.json`。本文按意图类型归类 miss、归纳典型失败模式，并据此给出对路由目录（`routing-catalog.json`，41 篇）与目录摘要的改进建议。

## 结论：miss 30 条，失败面以「多召」为主

30 条 miss 按偏差类型分三档：**超集误召 20 条**（期望文档全中，另夹带 1–2 篇近邻）、**部分命中 6 条**（多标签查询命中主意图、漏掉一篇次意图）、**零召回 4 条**（期望文档一篇未中）。26/30 条至少命中一篇期望文档——与上一版离线 hybrid 基线的失败面（金种子 60 条标注中 25 条零召回，漏召为主）正好互补：LLM 路由把「找不到」变成了「找太多」，决策门（核心桶 F1 提升达标 + 金种子达标 + 三臂盲评 B(1) > A(0)）据此通过，登记见 `docs/decisions/OPEN-DECISIONS.md`（O-路由v2，RESOLVED）。主评测集（1098 条）分桶宏平均见 `baseline-buckets.json`。

## 典型失败模式

1. **超集式宽召是最大模式（20/30）**：期望全中但夹带近邻——**03-依恋理论被当「情绪万金油」夹带 6 条**（沉默难受、心结、稳住情绪、异地吵架后不想沟通、安抚怀疑等只要带情绪词就多给一篇 03，其中 2 条同时还漏了次意图）；07-沟通冲突夹带 3 条；06-吸引、practical/场景感、13/14 历史近邻对、practical/万能吵架技巧各互吸 2 条；其余（20、19、01、主动表达、高情商拒绝、17、自然流、化解尴尬、05）各 1 条。这是精度问题而非召回问题：目录摘要没把近邻篇的分工边界讲清，分类器宁可多给。
2. **knowledge ↔ practical 边界摇摆（7 条）**：07 与万能吵架技巧、06 与主动表达 / 自然流两对在「怎么做」类 query 上互为夹带，且呈对称镜像——「一吵架就冷战」（07 全中 + 多万能吵架）对「老提陈年往事」（万能吵架全中 + 多 07）；「初次碰面表露好感」（主动表达全中 + 多 06）对「初次相见传递好感」（06 全中 + 多主动表达）。另有「怎么自然地搭讪陌生人」一条反向：gold 定位在 20-经典社交体系（搭讪这套东西的机制 / 证据 / 风险边界视角），预测全落在 how-to（06 + 自然流 + 拓展人脉），知识篇的证据 / 风险维度整条丢失。
3. **practical 近义话术篇互相抢（5 条）**：「夸女同事不像调情」gold 是 公开表达案例的伦理转译（职场公开场合 + 伦理维度），预测给了 万能夸人话术——意图里的「场合 + 伦理」约束词没被摘要覆盖；「被问尴尬隐私怎么转移话题」两条期望（实战话术编排器 + 场景感）全漏，给了 废话文学 + 巧妙接话；「场景感、松弛感与社交校准」一篇同时在 q17 / q18 被当兜底夹带、又在 q16 作为期望缺席——长标题实操篇的区分意图不在标题字面，摘要里缺「典型触发问法」。
4. **多标签查询的次意图漏召（6 条）**：漏的都是场景 / 维度型次意图——异地恋吵架漏 09（在线约会与数字关系）、老婆怀疑 / 父母吵架漏 11（婚姻家庭与生命周期，原生家庭场景词缺失）、索要私密照片漏 08（同意边界性——该条多召的 17-法律危机转介方向偏保守但不是主意图）、MBTI 科学看待漏 01、吃醋控制漏 07。多标签 gold 的次意图多为「场景定位」（异地 / 婚姻 / 原生家庭）与「证据 / 边界维度」（科学 / 同意），单靠主意图词匹配不到。
5. **01-证据分级作为「证据修饰词」的挂载口径不稳（3 例三走向）**：「书单有没有靠谱推荐」gold 期望 01（靠不靠谱 = 可信度议题），预测按字面「书单」召 19——零召回；「科学看待 MBTI」漏 01；「套路能信吗」却又多召 01。同一类「靠谱 / 能信吗 / 科学吗」修饰在 gold 标注与分类器之间没有一致规则。

**安全观察**：q26「网友未见面就索要私密照片」多召了 17-中国法律安全与危机转介、漏了 08——错误方向是「多转介」而非「漏转介」，属安全侧偏保守的一侧；后续改摘要应保持风险类 query「宁可多转介」的偏置，同时把 08-同意边界补成主意图。

## 对路由目录 / 摘要的改进建议

- **近邻篇在目录摘要里互相声明分工（收益最大）**：41 篇 `routing-catalog.json` 的摘要统一补一句「与 X 的分工」——07 ↔ 万能吵架技巧、06 ↔ 主动表达 / 自然流、02 ↔ 03、13 ↔ 14、19 ↔ 01——直接对准 20 条超集误召里的近邻夹带与 7 条边界摇摆。
- **practical 长标题篇提炼「意图词 + 典型触发问法」进摘要首句**：场景感 / 公开表达伦理转译 / 实战话术编排器三篇的 miss 都源于意图词不在标题字面；「职场 / 公开场合 / 不越界」「冷场 / 接话 / 关系推进」等触发词写进摘要即可区分近义话术篇。
- **01 的证据修饰词挂载规则先对齐 gold 再进摘要**：先在 gold 标注侧固化「靠不靠谱 / 能信吗 / 科学吗是否独立挂 01」的口径（3 例现状：零召回 / 漏召 / 多召各一），规则定了以后在 01 摘要里显式声明，消除双向漂移。
- **多标签次意图的场景词覆盖**：09 补「异地 / 线上 / 网友」、11 补「父母 / 原生家庭」、08 补「同意 / 边界 / 私密照」，直接对准 6 条次意图漏召。
- **回归闭环**：改目录 / 摘要后先跑 `RoutePredictionsDumpTest` 留逐条基线 diff（本清单 30 条即 LLM 档默认化后的首个回归基线），评测集改动过 `LeakGateTest` 泄漏门禁（阈值 8 字符），分桶宏平均对照 `baseline-buckets.json`；本分析随每次路由侧改动回填「归类 / 失败模式 / 建议」三节保持可复现。
