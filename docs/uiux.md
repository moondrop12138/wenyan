## 1. 设计方向（对标 DeepSeek 实测结论）

**DeepSeek 极简工具风为骨 + 情感陪伴"温暖克制"为魂。**

- 采用：白/浅灰底、消息气泡式对话、底部圆角输入栏（左侧功能开关、右侧发送箭头）、零装饰高专注、大留白
- 不采用：豆包式活泼、文心式高信息密度、心动类 App 的粉红心形 + emoji 堆砌 + 毛玻璃渐变玻璃拟态（新鲜度过即疲劳）
- 正面参考：暮色/余白风格——低饱和 + 大量留白 + 书信式对话
- 设计三轴：**Variance 5 / Motion 4 / Density 3**（克制、克制的动效、大留白）

## 2. 设计 Token（草案，Phase 2 输出正式 design-tokens.json）

### 配色

| Token | 浅色 | 深色 | 用途 |
|-------|------|------|------|
| --bg | #FFFFFF | #0F1117 | 页面背景（深色=深夜场景主战场） |
| --surface | #F7F8FA | #161B22 | 卡片/输入栏 |
| --fg | #111827 | #F2F4F8 | 主文字 |
| --muted | #6B7280 | #8B949E | 次级文字 |
| --accent | #4D6BFE | #4D6BFE | 主色（DeepSeek 深蓝，**纯色非渐变**） |
| --border | #E5E7EB | #262B36 | 分隔线/描边 |
| --success | #16A34A | 同 | 语义 |
| --warn | #D97706 | 同 | 语义 |
| --danger | #DC2626 | 同 | 语义 |
| --warm | #E8873E | 同 | 仅分析结果页"行动收束"步骤标签，每屏 ≤1 处 |

配比：中性色 >80%｜强调色 ≈8%｜语义/效果 <5%。

### 字体

- 系统字体栈：Roboto / Noto Sans SC（安卓原生，零性能开销）
- 标题 Medium/Semibold 加大字号；正文 400
- API Key 输入场景可选等宽字体

### 图标（已锁定一套）

- **Material Symbols（Outlined）**：Jetpack Compose 原生可用、统一 24dp 网格、语义清晰、无版权成本
- 尺寸体系：16px 行内 / 20px 按钮内 / 24px 独立图标，全项目统一
- 禁 emoji 图标、禁多套图标库混用

## 3. 页面设计要点

### P1 对话首页
- 顶部标题 + 设置入口
- 用户气泡右侧（主色），AI 气泡左侧（灰底圆角）
- 底部圆角输入框：回形针（粘贴/截图入口）+ 圆形主色发送按钮
- 流式回复：打字机光标 + 三点思考指示（150ms 间隔）
- **空状态** = 引导文案 + 示例问题 chips（"他三天没回消息怎么回"）+ 粘贴记录/截图入口

### P2 首启问卷页（4 屏）
- 一屏一题，顶部进度条 + "跳过，直接开聊"（跳过需二次确认）
- 选项卡片式，底部主色"下一步"
- 首屏文案："先让我认识你和局面"
- 题序：本人资料 → 对象资料 → 关系经过 → 目标 + 情绪强度

### P3 分析结果页
- 五段式卡片：情绪落地 / 事实拆分 / 利益判断 / 明确建议 / 行动收束，可折叠，结论置顶
- 建议卡主色高亮 + 一键复制按钮
- 展示"本次分析参考了哪份资料"（知识透明）
- "这句怎么回"模式：第一屏先给可复制成品

### P4 设置页
- 分组列表：**模型服务**（提供商管理）/ 主题（浅色/深色/跟随系统）/ 隐私（一键清除档案）
- **提供商管理（Chatbox 式）**：
  - 提供商列表页：内置预设（DeepSeek / 智谱 / OpenAI / 通义 / Kimi）+ 自定义，每项显示名称与当前状态，点击进入编辑
  - 提供商编辑页：名称 / API Host（Base URL）/ API Key（密文 + 显隐切换）/ 模型列表管理（增删、多模态能力开关、设为默认）+ "测试连接"按钮（返回 200/401/429 明确结果）
  - "添加提供商"入口：新建自定义提供商（支持 Ollama 等本地服务）
- **当前模型**：主模型选择（从全部模型库选择，含"支持看图"徽标）；**视觉模型**独立选择（仅列出多模态能力模型，附说明："用于非多模态主模型的截图分析"）
- 隐私声明明示"数据发送至用户配置的第三方服务"

### P5 对话页模型切换器
- 对话页顶部：当前模型名（点击弹出模型选择底部弹层）
- 底部弹层：提供商分组 → 模型列表（带能力徽标），选中项主色高亮，切换即时生效不中断对话

### P5 截图分析分流提示（双通道）
- 选图后按主模型能力分流：
  - 主模型多模态 → 直发分析，无额外提示
  - 主模型非多模态 → 提示"当前模型不支持看图，将先用视觉模型提取截图文字再分析"（通道 B）
  - 视觉模型未配置 → 引导文案："截图分析需要一个支持看图的模型，去设置页配置"
- 通道 B 转述结果展示："AI 从截图中读出了这些内容"卡片，可编辑修正后确认分析

### P6 空状态/错误态
- 中心图标 + 引导文案 + 主操作按钮
- 错误态：401 Key 无效 / 429 限流 / 502 服务异常，明确文案 + 重试

## 4. 交互细节

- 深色模式与浅色模式首发同等体验（深夜场景是主战场），深色需手动调对比度，不可直接反色
- 高情绪（评分 >7）：先出安抚 + 暂存建议，再进完整分析
- 问卷跳过需二次确认（对应 SKILL"紧急例外"原则）
- 流式回复支持中途停止
